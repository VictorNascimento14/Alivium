# Alivium — Alívio da Dor

Aplicação para adultos com proposta de **acolhimento, reflexão, cuidado e esperança**. Funciona em
celular, tablet e computador.

> Este repositório é o **front-end**. Não existe backend na v1: os dados vivem no navegador, atrás de
> uma camada (`src/dados/`) pensada para ser trocada por uma API depois.

## Funcionalidades

- Cadastro e login
- Área inicial personalizada, com check-in de humor
- Conteúdos organizados por categorias
- Jornadas de acompanhamento, etapa por etapa
- Registro de progresso e diário de reflexões
- Área administrativa para gerenciar categorias, conteúdos e jornadas
